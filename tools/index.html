Neurodiversity Aotearoa

Tools

Free, browser-based assessments and check-ins for use with neurodivergent students. Each tool opens on its own, runs entirely in the browser, and keeps results on-device until you choose to save or print them.

📝

Schonell Spelling Test

Reads each graded word aloud — and in a sentence — while the student types their answer. Auto-marks responses, stops after five wrong in a row, and converts the score to a spelling age.

Check-in Wheels

Two self check-in wheels — Executive Function and ASD — that let a student rate how true each statement feels for them, then visualise the result as a wheel they can save or print.
